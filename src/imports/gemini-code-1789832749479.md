# CADS High-Fidelity UI/UX Design Prompts for Figma Make

Use these highly detailed prompts in Figma Make (or similar AI UI generators) to produce an excellent, user-centric, and accessible interface. The design language focuses on a modern government SaaS aesthetic: high trust, low cognitive load, and highly efficient data entry.

## Phase 1: Authentication and Login Screen
> Design a premium, high-fidelity secure login screen for a government web application named "CADS: Computerized Assessment of Discernment System". Use a modern SaaS aesthetic with a Tailwind CSS color palette featuring deep navy blue (`bg-blue-900`), crisp white, and subtle slate grays (`text-slate-500`). 
> 
> **Layout:** Split-screen desktop layout (50/50). 
> **Left Side:** A soft, gradient background (navy to blue-600) featuring a high-quality, abstract 3D or isometric illustration of a secure document workflow, layered with a subtle watermark of a government seal. 
> **Right Side:** A crisp white background centered with a beautifully spaced login card. 
> **Card Details:** Include a bold, sans-serif heading "Welcome to CADS" and a muted subheading "Sign in to manage MSWDO assessments." The input fields (Username, Password) should have clear labels, light gray borders (`border-slate-300`), subtle rounded corners (`rounded-lg`), and placeholder text. Include a sleek "Eye" icon inside the password field. The "Secure Login" button must be full-width, solid navy blue, with a subtle hover shadow. Add a "Forgot Password?" link aligned to the right. Use the 'Inter' font family for perfect readability.

## Phase 2: Case Monitoring Dashboard
> Design a modern, data-dense but clean administrative dashboard for case monitoring. Use a light background (`bg-slate-50`) to make content cards pop. 
> 
> **Navigation:** A sleek left-hand sidebar (dark navy blue) with active states highlighted in a lighter blue accent. Sidebar items (with sleek outline icons): Dashboard, CICL Intake, Assessments, Reports, Settings. 
> **Top Bar:** A clean white header with a global search input (featuring a magnifying glass icon and a `/` keyboard shortcut hint), a notification bell with a red indicator dot, and a user profile avatar with a dropdown chevron. 
> **Hero Section:** A greeting "Good Morning, Assessor" with three horizontal metric cards. Each card must have a subtle drop shadow (`shadow-sm`), rounded corners (`rounded-xl`), an icon inside a soft colored circle, a large metric number, and a trend indicator (e.g., "+2 this week"). 
> **Data Table:** A spacious, full-width white card below the metrics titled "Active CICL Cases". The table should have clear column headers (Case ID, Name, Age, Referral Date, Status, SLA Countdown) with a light gray background (`bg-slate-100`). Include status badges with soft backgrounds and bold text (e.g., soft green for "Safe", soft yellow for "Pending", soft red for "Urgent < 24h"). Add a kebab menu (three vertical dots) at the end of each row for actions.

## Phase 3: Digital Intake Form (Wizard Layout)
> Design a highly ergonomic, multi-step data entry interface for a comprehensive Intake Form. 
> 
> **Layout Structure:** A two-column layout. The left column (25% width) acts as a vertical progress stepper (Steps: 1. Identifying Data, 2. Family Composition, 3. Circumstances, 4. Review). The active step should be connected by a solid blue line, with inactive steps in muted gray. 
> **Main Form Area:** A large white card container (`shadow-md`, `rounded-xl`). Inside, group related fields using an elegant CSS grid. For example, "First Name", "Middle Name", and "Last Name" in a 3-column grid. 
> **UI/UX Details:** Input fields should have focus rings (`ring-2 ring-blue-500`). Use floating labels or very clear typography for field names. Include a highly usable Date Picker component. For the "Offense Committed" section, design a clean dropdown menu with a search filter inside it. 
> **Action Bar:** A sticky footer at the bottom of the white card with a "Save as Draft" button (ghost style, gray) on the left, and "Previous" (outline) and "Next Step" (solid blue) buttons aligned to the right.

## Phase 4: Distraction-Free Assessment Questionnaire
> Design a focused, distraction-free assessment interface optimized for reducing cognitive load during live interviews (LMD/IVJ/CFC tools). 
> 
> **Top Navigation:** A minimalist top bar showing only the tool name (e.g., "Levels of Moral Development") and a smooth, animated horizontal progress bar spanning the width of the screen, indicating "Question 4 of 14". 
> **Main Content:** Centered single-column layout. Display the "Moral Dilemma" text in a large, readable serif font (like Merriweather or Georgia) to make reading long text easier. 
> **Interaction Area:** Below the text, present the answers as a vertical list of large, clickable cards rather than tiny radio buttons. When an answer card is selected, it should highlight with a light blue background (`bg-blue-50`) and a blue border (`border-blue-500`), along with a checkmark icon. 
> **Notes Section:** Include a collapsible or elegantly integrated text area labeled "Assessor's Observation Notes (Optional)" with a subtle gray background. 
> **Controls:** Large, easily clickable "Previous" and "Next" buttons at the bottom. Add a "Pause Assessment" button discreetly in the top right corner.

## Phase 5: Assessment Results & Report Generation
> Design an analytical and report generation screen that bridges data visualization with document management. 
> 
> **Layout:** A 40/60 split-screen layout. 
> **Left Column (Analytics):** A scrollable dashboard of the assessment results. Use visually appealing gauge charts or circular progress rings to display the LMD score (e.g., 4.5/6) and IVJ score. Display CFC and FFC results using distinct color-coded alert boxes (e.g., a soft red box with a warning icon for "Very Dysfunctional", a soft green box for "Highly Functional"). Include a clear typography hierarchy detailing the automated interpretation. 
> **Right Column (Document Preview):** A dark gray background (`bg-slate-800`) framing a centered, highly realistic A4 paper mockup (`bg-white`, `shadow-2xl`, `aspect-[1/1.4]`). The paper should display a skeleton preview of the formal "Social Case Study Report" with official letterheads and formatted text blocks. 
> **Floating Action Bar:** Hovering at the top or bottom of the document preview, design a sleek toolbar containing a primary "Export PDF" button (with a download icon), a "Print" button, and an "Edit Content" button.
